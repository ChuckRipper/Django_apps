# Django_apps
Do realizowania zadań z przedmiotu "Aplikacje internetowe w Django"

## Zadania – Aplikacje internetowe w Django

Każdy folder `temat_N` to samodzielny projekt Django (własny `manage.py`, baza i `requirements.txt`).

| Folder | Zadanie | Uruchomienie |
|---|---|---|
| `temat_2` | Blog (CRUD z obrazkami + formularz kontaktowy) | `cd temat_2` → `python manage.py runserver` |
| `temat_3` | System zarządzania biblioteką + wypożyczenia | `cd temat_3` → `python manage.py runserver` |

Szczegóły w `README.md` każdego tematu.
